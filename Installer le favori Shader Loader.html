Favori « → Shader Loader »

Un seul favori pour importer depuis shadertoy.com, shadered.org, shaderkit.com, fragcoord.xyz, shaderoo.org et neort.io. Il marche dans Firefox, Chrome et Edge.

  1. Affiche la barre de favoris de ton navigateur : appuie sur Ctrl + Maj + B.
  2. Fais glisser ce bouton bleu (clic maintenu) jusque dans la barre de favoris, puis relâche :

    → Shader Loader

  3. Ouvre un shader sur Shadertoy, SHADERed, ShaderKit, FragCoord, Shaderoo ou NEORT.
  4. Clique sur → Shader Loader dans ta barre de favoris. Un fichier se télécharge, et le shader apparaît dans Resolume (la fenêtre Browse Library doit avoir été ouverte au moins une fois).
